Who’s That Footballer? ⚽
A simple football quiz where users identify Neymar Jr, Lamine Yamal and Mbappé from their photos. Choose an answer for each question, submit your answers and see how many you got right. I built this app using the React Native concepts I learnt in class.

# Features Highlight
Photo questions: The quiz has three questions. I used the Image component to display each footballer’s photo through an online link.
Dropdown answers: Each question has a Picker with three footballers to choose from. The selection starts at “-”, and useState stores the user’s chosen answer.
Score and feedback: Pressing “Submit Answers” checks the answers using if statements. An Alert displays the score out of three, along with feedback such as “Keep trying!” or “Hat-trick! Well done!”
Try again: Users can change their answers and submit again. The score starts from zero each time.
Simple layout: I used ScrollView so users can scroll through the questions, with basic styling to give the app a baby blue theme.
